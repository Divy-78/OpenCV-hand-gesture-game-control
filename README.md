# Hand Gesture Controlled Subway Surfers

A computer vision project built using Python and OpenCV that allows users to control Subway Surfers using real-time hand gestures captured through a webcam.

---

## Features

- Real-time hand gesture detection
- Webcam-based controls
- Gesture-controlled gameplay
- Fast and interactive system

---

## Technologies Used

- Python
- OpenCV
- MediaPipe
- PyAutoGUI

---

## How It Works

- Captures webcam video
- Detects hand landmarks using MediaPipe
- Recognizes gestures
- Converts gestures into keyboard/game controls
- Controls Subway Surfers in real time
